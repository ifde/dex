# Constructor of Dynamic Fees for Decentralized Exchanges (DEX) Project

## О проекте

Данный проект представляет собой библиотеку смарт-контрактов (хуков) для DEX на основе Uniswap V4, которая позволяет автоматически корректировать размер комиссии пула ликвидности в зависимости от рыночных условий.

### Основные возможности

- Динамический расчет комиссии — автоматическая корректировка на основе заданного алгоритма (волатильность, объем торгов, арбитражный спред и др.).
- Интеграция с Chainlink — получение актуальных ценовых данных с централизованных бирж для внешних алгоритмов.
- Совместимость с экосистемой Uniswap V4 — PoolManager, SwapRouter, PositionManager.
- Сквозное тестирование — локальный блокчейн (Anvil) с симуляцией торговой активности.
- Развертывание — скрипты для тестовых и основных сетей.
- Веб-интерфейс конструктора — выбор алгоритма, просмотр генерируемого кода и скачивание готового проекта.

## Целевая аудитория

- Разработчики DeFi-протоколов
- Команды, создающие специализированные DEX
- Профессиональные поставщики ликвидности (LP)

## Экономический эффект

Ориентировочная экономия для крупного пула ликвидности — от 1 000 до 10 000 долларов в месяц за счет снижения непостоянных потерь (impermanent loss) и оптимизации комиссионных доходов.

## Технологический стек

### Смарт-контракты и инфраструктура

- Solidity (версия 0.8.0 и выше)
- Foundry (Forge, Cast, Anvil)
- Uniswap V4 Core & Periphery
- OpenZeppelin UniswapHooks
- Chainlink (версия 0.2.7 и выше)

### Анализ и тестирование

- Python 3.10 и выше (исторические данные, анализ эффективности)
- Binance Market Data API

### Веб-интерфейс

- Flask

## Состав проекта

- Библиотека смарт-контрактов (хуки динамических комиссий)
- Скрипты развертывания и тестирования
- Веб-интерфейс конструктора
- Скрипты для анализа эффективности на исторических данных


## How to run locally

`python -m venv .venv`

`source ./.venv/bin/activate`

`pip install -r requirements.txt`

```
python ./web_interface/app.py
```
